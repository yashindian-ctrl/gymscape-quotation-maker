# Ganpati Trading & Gymscape — Quotation & Invoice Studio

A modern, interactive Quotation and Invoice Maker Studio customized for **GANPATI TRADING** (Brand: *KROSFITSPORTS&ATHLETICS / GYMSCAPE*).

![Quotation Studio](https://img.shields.io/badge/Status-Active-emerald) ![Tech](https://img.shields.io/badge/Stack-HTML5%20%7C%20CSS3%20%7C%20Vanilla%20JS-blue)

---

## 🌟 Key Features

- **Live WYSIWYG A4 Document Preview**: Real-time side-by-side editing and document rendering.
- **Pre-Loaded Firm Details**: Pre-filled with Ganpati Trading office address, GSTIN (`09BZIPB3705K1ZD`), HDFC Bank payment details, and terms & conditions.
- **Optional Product Images**:
  - Global toggle to include or hide the Product Image column.
  - Per-item image upload (PNG, JPG, SVG) with remove / clear options.
  - Built-in sports equipment illustrations.
- **1-Click Catalog Presets**: Quick insert for Commercial Pool Tables, Foosball, Air Hockey, Table Tennis, Commercial Treadmills, and CrossFit setups.
- **Auto Calculations & Words**: Live Subtotal, 18% GST toggle, Freight/Transport, Discounts, Grand Total, and Indian numbering amount-to-words.
- **Unified Page 1 Document**: Includes customer details, order reference, item specifications, bottom notes, bank payment details, terms & conditions, and authorized signatory on a single clean A4 document.
- **Export Capabilities**:
  - Direct pixel-perfect PDF export (`html2pdf.js`).
  - Native browser print styling (`@media print`).
  - WhatsApp text summary generator for quick messaging.
  - Local drafts management & JSON backup/restore.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js npx serve
npx serve .
```

Open `http://localhost:8080` in your browser.
